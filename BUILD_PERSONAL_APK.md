# Building AGENT OX Signed Personal APK

1. Open Android Studio.
2. File -> Open -> /home/devil/Desktop/agent
3. Wait for Gradle sync to complete.
4. Build -> Generate Signed Bundle / APK...
5. Select APK -> Next.
6. Choose or create your keystore.
7. Select 'release' -> Finish.
8. Locate app-release.apk and install on your device!
