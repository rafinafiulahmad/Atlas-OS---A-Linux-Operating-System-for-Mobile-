## ⚡ Core Capabilities (Titan 11-in-1 Suite)
- 🌐 **Local Web Server**: Native HTTP server on port 8080 for mobile-to-PC file transfer.
- ⌨️ **Hacker Keybar**: On-screen keyboard bar with Tab, Esc, Ctrl, Pipe, and Linux shortcuts.
- 💓 **Live Hardware Pulse**: 2-second real-time auto-refresh of RAM, CPU status & thermals.
- 📶 **Network Ping Diagnostics**: Live socket ping test to Google DNS (8.8.8.8) in ms.
- 🌓 **Dynamic Theme Matrix**: Instant toggle between AMOLED Dark Mode and Light Mode.
- ⚡ **Linux Task Manager**: Process discovery, PID tracking, and process kill signal.
- 🔬 **Hardware Telemetry**: Real-time refresh rate (60/90/120Hz), DPI, and Gyroscope tracking.
- 📁 **Code Scaffold & Exporter**: Instant templates for Python, Node.js, C++ and 1-click ZIP exporter.

## 📥 Quick Installation
Download the pre-compiled ATLAS-OS.apk from the Releases section and install directly on your Android phone.

## 🛠️ Build from Source
```bash
git clone https://github.com/rafinafiulahmad/Atlas-OS---A-Linux-Operating-System-for-Mobile-.git
cd Atlas-OS---A-Linux-Operating-System-for-Mobile-
./gradlew assembleDebug
```
